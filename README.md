# ✅ TaskFlow: Efficient Task Management App

A modern, full-stack application designed to help teams and individuals organize, track, and complete their daily tasks with ease.

## 🚀 Key Features
- **Smart Task Management:** Create, edit, and delete tasks with ease.
- **Drag-and-Drop Kanban:** Move tasks between "To-Do," "In Progress," and "Done."
- **Priority Labeling:** Categorize tasks by urgency (High, Medium, Low).
- **User Authentication:** Secure login and account-based task storage.
- **Dark Mode Support:** Optimized for productivity day or night.

## 🏁 Getting Started

### Prerequisites
- Node.js (v16+)
- A modern web browser

### Installation
1. **Clone the repo:**
   ```bash
   git clone https://github.com
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Set up Environment Variables:**
   Create a `.env` file and add your database URL and API keys.

4. **Run the App:**
   ```bash
   npm run dev
   ```
